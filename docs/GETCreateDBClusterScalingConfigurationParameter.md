

# GETCreateDBClusterScalingConfigurationParameter

<p>Contains the scaling configuration of an Aurora Serverless v1 DB cluster.</p> <p>For more information, see <a href=\"https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/aurora-serverless.html\">Using Amazon Aurora Serverless v1</a> in the <i>Amazon Aurora User Guide</i>.</p>

## Properties

| Name | Type | Description | Notes |
|------------ | ------------- | ------------- | -------------|
|**minCapacity** | **Integer** | &lt;p&gt;The minimum capacity for an Aurora DB cluster in &lt;code&gt;serverless&lt;/code&gt; DB engine mode.&lt;/p&gt; &lt;p&gt;For Aurora MySQL, valid capacity values are &lt;code&gt;1&lt;/code&gt;, &lt;code&gt;2&lt;/code&gt;, &lt;code&gt;4&lt;/code&gt;, &lt;code&gt;8&lt;/code&gt;, &lt;code&gt;16&lt;/code&gt;, &lt;code&gt;32&lt;/code&gt;, &lt;code&gt;64&lt;/code&gt;, &lt;code&gt;128&lt;/code&gt;, and &lt;code&gt;256&lt;/code&gt;.&lt;/p&gt; &lt;p&gt;For Aurora PostgreSQL, valid capacity values are &lt;code&gt;2&lt;/code&gt;, &lt;code&gt;4&lt;/code&gt;, &lt;code&gt;8&lt;/code&gt;, &lt;code&gt;16&lt;/code&gt;, &lt;code&gt;32&lt;/code&gt;, &lt;code&gt;64&lt;/code&gt;, &lt;code&gt;192&lt;/code&gt;, and &lt;code&gt;384&lt;/code&gt;.&lt;/p&gt; &lt;p&gt;The minimum capacity must be less than or equal to the maximum capacity.&lt;/p&gt; |  [optional] |
|**maxCapacity** | **Integer** | &lt;p&gt;The maximum capacity for an Aurora DB cluster in &lt;code&gt;serverless&lt;/code&gt; DB engine mode.&lt;/p&gt; &lt;p&gt;For Aurora MySQL, valid capacity values are &lt;code&gt;1&lt;/code&gt;, &lt;code&gt;2&lt;/code&gt;, &lt;code&gt;4&lt;/code&gt;, &lt;code&gt;8&lt;/code&gt;, &lt;code&gt;16&lt;/code&gt;, &lt;code&gt;32&lt;/code&gt;, &lt;code&gt;64&lt;/code&gt;, &lt;code&gt;128&lt;/code&gt;, and &lt;code&gt;256&lt;/code&gt;.&lt;/p&gt; &lt;p&gt;For Aurora PostgreSQL, valid capacity values are &lt;code&gt;2&lt;/code&gt;, &lt;code&gt;4&lt;/code&gt;, &lt;code&gt;8&lt;/code&gt;, &lt;code&gt;16&lt;/code&gt;, &lt;code&gt;32&lt;/code&gt;, &lt;code&gt;64&lt;/code&gt;, &lt;code&gt;192&lt;/code&gt;, and &lt;code&gt;384&lt;/code&gt;.&lt;/p&gt; &lt;p&gt;The maximum capacity must be greater than or equal to the minimum capacity.&lt;/p&gt; |  [optional] |
|**autoPause** | **Boolean** | &lt;p&gt;A value that indicates whether to allow or disallow automatic pause for an Aurora DB cluster in &lt;code&gt;serverless&lt;/code&gt; DB engine mode. A DB cluster can be paused only when it&#39;s idle (it has no connections).&lt;/p&gt; &lt;note&gt; &lt;p&gt;If a DB cluster is paused for more than seven days, the DB cluster might be backed up with a snapshot. In this case, the DB cluster is restored when there is a request to connect to it.&lt;/p&gt; &lt;/note&gt; |  [optional] |
|**secondsUntilAutoPause** | **Integer** | &lt;p&gt;The time, in seconds, before an Aurora DB cluster in &lt;code&gt;serverless&lt;/code&gt; mode is paused.&lt;/p&gt; &lt;p&gt;Specify a value between 300 and 86,400 seconds.&lt;/p&gt; |  [optional] |
|**timeoutAction** | **String** | &lt;p&gt;The action to take when the timeout is reached, either &lt;code&gt;ForceApplyCapacityChange&lt;/code&gt; or &lt;code&gt;RollbackCapacityChange&lt;/code&gt;.&lt;/p&gt; &lt;p&gt; &lt;code&gt;ForceApplyCapacityChange&lt;/code&gt; sets the capacity to the specified value as soon as possible.&lt;/p&gt; &lt;p&gt; &lt;code&gt;RollbackCapacityChange&lt;/code&gt;, the default, ignores the capacity change if a scaling point isn&#39;t found in the timeout period.&lt;/p&gt; &lt;important&gt; &lt;p&gt;If you specify &lt;code&gt;ForceApplyCapacityChange&lt;/code&gt;, connections that prevent Aurora Serverless v1 from finding a scaling point might be dropped.&lt;/p&gt; &lt;/important&gt; &lt;p&gt;For more information, see &lt;a href&#x3D;\&quot;https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/aurora-serverless.how-it-works.html#aurora-serverless.how-it-works.auto-scaling\&quot;&gt; Autoscaling for Aurora Serverless v1&lt;/a&gt; in the &lt;i&gt;Amazon Aurora User Guide&lt;/i&gt;.&lt;/p&gt; |  [optional] |
|**secondsBeforeTimeout** | **Integer** | &lt;p&gt;The amount of time, in seconds, that Aurora Serverless v1 tries to find a scaling point to perform seamless scaling before enforcing the timeout action. The default is 300.&lt;/p&gt; &lt;p&gt;Specify a value between 60 and 600 seconds.&lt;/p&gt; |  [optional] |
